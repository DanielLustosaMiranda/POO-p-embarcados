# Módulo 0: Preparando o Ambiente de Desenvolvimento

Antes de começarmos a criar nossas classes e programar os robôs, precisamos preparar nossa ferramenta de trabalho. Utilizaremos o **Visual Studio Code (VS Code)** juntamente com a extensão **PlatformIO**, que é uma plataforma profissional e muito robusta para desenvolvimento de sistemas embarcados como o ESP32.

---

## 1. Instalando a extensão PlatformIO no VS Code

O PlatformIO substitui a IDE padrão do Arduino, oferecendo recursos avançados como autocompletar eficiente, organização de pastas e fácil gerenciamento de bibliotecas.

**Passo a passo da instalação:**

1. Abra o **Visual Studio Code**.
2. Na barra lateral esquerda, clique no ícone de **Extensions** (Extensões) ou pressione o atalho `Ctrl+Shift+X`.
3. Na barra de pesquisa que aparecerá no topo, digite `PlatformIO IDE`.
4. O primeiro resultado oficial geralmente terá um ícone de uma "formiga alienígena". Clique no botão azul **Install** (Instalar).
5. **Aguarde:** O processo de instalação do PlatformIO é um pouco mais demorado do que as extensões comuns. Ele precisa instalar o núcleo em Python e ferramentas de compilação em segundo plano. Você verá o progresso no canto inferior direito da tela.
6. Quando a instalação terminar, aparecerá uma notificação pedindo para **Recarregar (Reload)** o VS Code. Confirme clicando no botão para reiniciar a janela.
7. Após o recarregamento, você notará o ícone do PlatformIO (a cabeça de formiga) na barra lateral esquerda e um menu de atalhos em formato de ícones na barra inferior azul do VS Code.

---

## 2. Criando um Novo Projeto para o ESP32

Com o ambiente pronto, vamos criar nosso projeto base.

**Passo a passo:**

1. Na barra inferior do VS Code, clique no ícone de **Home** (uma casinha) para abrir a tela inicial do PlatformIO. *(Alternativa: Clique no ícone do PlatformIO na barra lateral esquerda e depois em "PIO Home > Open").*
2. Na aba que se abriu, clique no botão **"+ New Project"**.
3. Um assistente (Project Wizard) será exibido. Preencha da seguinte maneira:
   - **Name (Nome):** Escolha um nome para seu projeto, por exemplo, `MeuRoboOOP` ou `Aula_Robo`. Evite espaços, acentos ou caracteres especiais.
   - **Board (Placa):** Pesquise pelo modelo do seu ESP32. O mais comum para aprendizado e kits básicos é o **"DOIT ESP32 DEVKIT V1"** ou o **"Espressif ESP32 Dev Module"**.
   - **Framework:** Mantenha selecionado **"Arduino"**. Isso garante que usaremos a linguagem e estrutura de programação que já estamos habituados, mas aproveitando o poder do ESP32.
   - **Location:** Você pode desmarcar "Use default location" para escolher manualmente onde quer salvar a pasta do seu projeto.
4. Clique em **"Finish"** e aguarde.
5. **Importante:** Ao criar o primeiro projeto para uma placa específica, o PlatformIO baixa todo o framework (os arquivos centrais que fazem o ESP32 funcionar). Isso **pode demorar vários minutos** dependendo da sua internet. Tenha paciência!

---

## 3. Conhecendo a Estrutura do Projeto

Assim que o projeto carregar, olhe para o "Explorer" (ícone de arquivos no canto superior esquerdo). O PlatformIO cria automaticamente uma estrutura de pastas. 

O arquivo onde você vai escrever seu código fica sempre em:
📁 `src` > 📄 `main.cpp`

Abra o arquivo `main.cpp`. Você verá o esqueleto básico:

```cpp
#include <Arduino.h>

void setup() {
  // put your setup code here, to run once:
}

void loop() {
  // put your main code here, to run repeatedly:
}
```

> **Aviso Importante!**
> Diferente da IDE tradicional do Arduino (onde os arquivos são `.ino`), aqui no VS Code trabalhamos com arquivos C++ de verdade (`.cpp`). Por isso, **sempre** é necessário ter a linha `#include <Arduino.h>` no topo do seu `main.cpp` para que as funções conhecidas como `pinMode`, `digitalWrite` e `delay` funcionem.

## 4. Como Compilar e Enviar (Upload) para o ESP32

Na barra inferior azul do VS Code, o PlatformIO coloca os atalhos que você mais vai usar:

- **✓ (Build / Compilar):** Apenas verifica se o seu código tem erros de sintaxe (não envia para o ESP32). É ótimo para ir testando se a lógica está certa.
- **→ (Upload / Enviar):** Compila o código e grava ele fisicamente dentro do ESP32 conectado via USB.
- **🔌 (Serial Monitor):** Abre o terminal para você ver mensagens enviadas pelo comando `Serial.println()`.

**Para enviar seu primeiro código:**
1. Conecte o ESP32 ao computador utilizando um **Cabo USB de Dados** (muita atenção: vários cabos, especialmente de carregadores paralelos ou caixas de som, passam apenas energia e não servem para programação. O Windows não emitirá o som de "dispositivo conectado" se o cabo não tiver vias de dados).
2. Clique no ícone **→ (Upload)**.
3. O terminal inferior abrirá e você verá o progresso do envio. Quando aparecer a mensagem verde indicando **"SUCCESS"**, o código já estará rodando!

> **Dica de Solução de Problemas:**
> Se durante o Upload o terminal ficar travado na mensagem `Connecting...` e der erro, repita o processo e, **assim que a mensagem Connecting aparecer, aperte e segure o botão físico escrito "BOOT" na placa do seu ESP32** até que a gravação (uma porcentagem subindo) comece. Isso é normal em algumas placas ESP32 genéricas.
